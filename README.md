# DockerIranInstaller

اسکریپت نصب خودکار **Docker CE** روی **Ubuntu 24.04**، مخصوص سرورها و VPSهای ایرانی — به‌همراه آپدیت کامل سیستم، نصب پکیج‌های پایه‌ی مفید، تنظیم DNS شکن و Registry Mirror آروان‌کلود برای دور زدن محدودیت‌های شبکه‌ای هنگام نصب و Pull ایمیج‌ها.

## ✨ امکانات

- ✅ آپدیت کامل سیستم (`apt update` + `full-upgrade`) قبل از هر کاری
- ✅ نصب خودکار پکیج‌های پایه‌ی مفید (`mc`, `unzip`, `htop`, `git`, `tmux`, `fail2ban`, ...)
- ✅ نصب Docker CE از ریپازیتوری رسمی داکر (نسخه‌ی جدید فرمت `.sources`)
- ✅ نصب Docker Compose Plugin و Docker Buildx
- ✅ تنظیم خودکار DNS روی شکن (سازگار با systemd-resolved و resolv.conf ساده)
- ✅ تنظیم Registry Mirror آروان‌کلود در `daemon.json`
- ✅ حذف خودکار پکیج‌های قدیمی/تداخلی داکر (`docker.io`, `podman-docker`, ...)
- ✅ بکاپ خودکار از فایل‌های تنظیمات قبل از تغییر
- ✅ تست نهایی نصب با `hello-world` و گزارش کامل وضعیت
- ✅ پاک‌سازی پکیج‌های اضافی (`autoremove`/`autoclean`) و هشدار نیاز به ریبوت
- ✅ خروجی رنگی و لاگ‌دار برای پیگیری آسون مراحل

## 📋 پیش‌نیازها

- Ubuntu 24.04 (روی نسخه‌های دیگر هم با warning اجرا می‌شه، ولی تضمین‌شده نیست)
- دسترسی root
- اتصال به اینترنت

## 🚀 نصب و اجرا

```bash
git clone https://github.com/RealDream-Lab/DockerIranInstaller.git
cd DockerIranInstaller
chmod +x install-docker.sh
sudo ./install-docker.sh
```

یا اجرای مستقیم بدون کلون کردن:

```bash
curl -fsSL https://raw.githubusercontent.com/RealDream-Lab/DockerIranInstaller/main/install-docker.sh | sudo bash
```

## 📦 پکیج‌های پایه‌ای که نصب می‌شن

| پکیج                                                                                           | کاربرد                                    |
| ---------------------------------------------------------------------------------------------- | ----------------------------------------- |
| `mc`                                                                                           | فایل‌منیجر متنی (Midnight Commander)      |
| `unzip` / `zip`                                                                                | فشرده‌سازی و اکسترکت آرشیو                |
| `curl` / `wget`                                                                                | دانلود و تست شبکه                         |
| `htop`                                                                                         | مانیتورینگ منابع سیستم                    |
| `git`                                                                                          | کنترل نسخه                                |
| `net-tools`                                                                                    | دستورات `netstat`, `ifconfig` و...        |
| `tree`                                                                                         | نمایش درختی پوشه‌ها                       |
| `ncdu`                                                                                         | بررسی تعاملی فضای دیسک                    |
| `tmux`                                                                                         | نگه‌داشتن سشن‌ها زنده حتی بعد قطع SSH     |
| `rsync`                                                                                        | انتقال و بکاپ فایل                        |
| `jq`                                                                                           | پردازش JSON از خط فرمان                   |
| `ufw`                                                                                          | فایروال ساده (فقط نصب می‌شه، فعال نمی‌شه) |
| `fail2ban`                                                                                     | جلوگیری از حملات brute-force روی SSH      |
| `ca-certificates`, `gnupg`, `lsb-release`, `apt-transport-https`, `software-properties-common` | پیش‌نیازهای نصب داکر                      |

لیست کامل داخل متغیر `BASE_PACKAGES` در ابتدای اسکریپت قابل ویرایش (اضافه/حذف) است.

> ⚠️ `ufw` فقط نصب می‌شود و فعال نمی‌شود، چون فعال‌سازی بدون تعریف قانون برای پورت SSH می‌تواند دسترسی شما به سرور را قطع کند.

## ⚙️ تنظیمات پیش‌فرض

| مورد            | مقدار                                           |
| --------------- | ----------------------------------------------- |
| DNS اصلی        | `178.22.122.100` (Shecan)                       |
| DNS دوم         | `185.51.200.2` (Shecan)                         |
| DNS پشتیبان     | `1.1.1.1`, `8.8.8.8`                            |
| Registry Mirror | `https://docker.arvancloud.ir`                  |
| Log Driver      | `json-file` (حداکثر ۳ فایل، هر کدام ۱۰ مگابایت) |

اگه می‌خواید DNS یا Mirror رو تغییر بدید، مقادیر `DNS1`, `DNS2` و `ARVAN_DOCKER_MIRROR` رو در ابتدای اسکریپت ویرایش کنید.

## 📝 چه کاری انجام می‌ده؟

1. بررسی روت بودن و سازگاری نسخه‌ی اوبونتو
2. تنظیم DNS شکن
3. آپدیت لیست پکیج‌ها و اجرای full-upgrade
4. نصب پکیج‌های پایه (`mc`, `unzip`, `htop`, ...) و پیش‌نیازهای داکر
5. حذف پکیج‌های تداخلی داکر
6. افزودن کلید GPG و ریپازیتوری رسمی داکر
7. نصب Docker CE، CLI، containerd، Buildx و Compose
8. فعال‌سازی و اجرای سرویس داکر
9. تنظیم Registry Mirror آروان‌کلود
10. تست نصب با اجرای کانتینر `hello-world`
11. پاک‌سازی پکیج‌های اضافی و بررسی نیاز به ریبوت
12. نمایش خلاصه‌ی نسخه‌ها و وضعیت سرویس

## ⚠️ نکات مهم

- تغییرات روی `/etc/resolv.conf` ممکنه در صورت استفاده از netplan یا NetworkManager بعد از ریبوت بازنویسی بشن.
- از فایل‌های تنظیمات قبلی (`daemon.json`, `resolv.conf`) به‌صورت خودکار بکاپ گرفته می‌شه.
- اگه تست `hello-world` به هر دلیلی fail بشه (مثلاً در دسترس نبودن موقت Mirror آروان)، خود Docker نصب‌شده باقی می‌مونه؛ فقط پیام هشدار نمایش داده می‌شه.
- در پایان اجرا، اگه سیستم نیاز به ریبوت داشته باشه (مثلاً به‌خاطر آپدیت کرنل)، یک هشدار به همراه لیست پکیج‌های مربوطه نمایش داده می‌شه.
